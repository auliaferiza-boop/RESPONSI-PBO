### Cara Menjalankan Program (Pakai Intellij IDEA)
1. Buka aplikasi IntelliJ IDEA (kalau belum ada pasang dulu).
2. Klik ikon empat garis di pojok kiri atas lalu pilih Open(kalau muncul halaman awal langsung pencet open saja) lalu cari dan pilih folder project RESPONSI-PBO.
3. Pastikan semua file(kendaraan.java, mobil.java, motor.java, bisaDinyalakan.java, bisaDiservis.java, dan Main.java) ada dalam satu folder yang sama.
4. Buka file Main.java(klik dua kali) lalu klik ikon segitiga hijau(Run) yang ada di sebelah baris method void main atau klik kanan lalu klik Run 'Main'. 
5. Tunggu sampai proses selesai lalu hasil pengujian program akan muncul.
